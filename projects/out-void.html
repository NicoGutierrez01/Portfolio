ABOUT THE PROJECT

ENTER. FIGHT. DESCEND.

OUT-VOID is a single-player FPS roguelike focused on procedural level generation and dynamic combat. Each run is designed to offer different encounters and environments while maintaining fast and responsive first-person gameplay.

02

MY ROLE

PROGRAMMING & GAME DESIGN.

I work as one of the programmers and game designers on OUT-VOID, contributing to gameplay systems, technical implementation and design decisions throughout development.

PROGRAMMING

Gameplay systems, core mechanics and technical implementation using Unity and C#.

GAME DESIGN

Collaborative design of mechanics, combat, progression and the overall player experience.
