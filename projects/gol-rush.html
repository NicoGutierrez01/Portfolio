ABOUT THE PROJECT

TABLE FOOTBALL. REIMAGINED.

GOL RUSH is a 3D reinterpretation of classic table football developed in Unreal Engine 5. Designed as a local competitive experience, the project brings the precision, nostalgia and fast-paced nature of traditional foosball into a digital arcade game.

02

MY ROLE

SOLE PROGRAMMER.

I was responsible for the complete programming of GOL RUSH, including player controls, ball physics, goal and scoring systems, match flow, victory conditions, menu logic, camera, lighting and audio implementation. Visual design and artistic production were handled by my teammate, while game design decisions were made collaboratively.

PROGRAMMING

Complete implementation of gameplay systems, mechanics and game logic using Unreal Engine 5.

GAME DESIGN

Collaborative design of the gameplay rules, controls and overall competitive experience.

03

PROGRAMMING BREAKDOWN

THE MATCH. BUILT IN CODE.

PLAYER CONTROLS

Foosball bar movement and local player input implemented with joystick controls.

BALL PHYSICS

Physical ball behaviour and collision interactions designed for responsive table football gameplay.

GOAL & SCORE

Goal detection, scoreboard updates and automatic match reset after each goal.

MATCH FLOW

Core match logic and victory conditions based on each player's score.

MENU

Main menu flow and transition into the local competitive match.

PRESENTATION & AUDIO

Camera setup, lighting implementation and sound integration throughout the experience.
