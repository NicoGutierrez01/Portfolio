ABOUT THE PROJECT

CLIMB. SURVIVE. GO HIGHER.

Eternal Jump is a 2D endless jumper where the player controls an adventurer equipped with a jetpack. The objective is to climb as high as possible by jumping between platforms, collecting power-ups and avoiding obstacles before falling or running out of time.

02

MY ROLE

SOLO DEVELOPMENT.

Eternal Jump was developed entirely by me as my first academic video game project. I was responsible for both programming and game design throughout the development process.

PROGRAMMING

Gameplay logic, mechanics and implementation using Phaser.

GAME DESIGN

Core gameplay loop, rules, progression and player experience.
